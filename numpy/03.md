## 3.1 Introduction

Mathematical operations in NumPy are:

- **Vectorized** (operate on entire arrays)
- **Fast** (implemented in optimized C backend)
- Core to ML tasks such as normalization, loss computation, gradient updates

---

## 3.2 Element-wise Operations

Operations are applied **element-by-element** between arrays of the same shape (or broadcastable shapes).

---

### Basic Operations

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(a + b)  # [5 7 9]
print(a - b)  # [-3 -3 -3]
print(a * b)  # [4 10 18]
print(a / b)  # [0.25 0.4 0.5]
```

---

### Important Note

- `*` → element-wise multiplication
- Not matrix multiplication

Matrix multiplication uses:

```python
np.dot(a, b)
# OR
a @ b
```

---

## 3.3 Universal Functions (ufuncs)

**Ufuncs** are fast, vectorized functions that operate on arrays.

---

### Common ufuncs

#### (1) Square Root

```python
np.sqrt(a)
```

---

#### (2) Exponential

```python
np.exp(a)
```

---

#### (3) Logarithm (Natural Log)

```python
np.log(a)
```

---

### Example

```python
a = np.array([1, 4, 9])

print(np.sqrt(a))  # [1. 2. 3.]
print(np.exp(a))   # e^x
print(np.log(a))   # ln(x)
```

---

### Why ufuncs are important in ML

- Used in:
  - Activation functions (ReLU, sigmoid)
  - Loss functions (log-loss)
  - Feature scaling

---

## 3.4 Aggregation Functions

Aggregation reduces array to a single value (or lower dimension).

---

### (1) Sum

```python
np.sum(a)
```

---

### (2) Mean (Average)

```python
np.mean(a)
```

---

### (3) Median

```python
np.median(a)
```

---

### (4) Standard Deviation

```python
np.std(a)
```

---

### (5) Variance

```python
np.var(a)
```

---

### Example

```python
a = np.array([1, 2, 3, 4, 5])

print(np.sum(a))     # 15
print(np.mean(a))    # 3.0
print(np.median(a))  # 3.0
print(np.std(a))     # ~1.41
print(np.var(a))     # 2.0
```

---

## 3.5 Axis-Based Operations (Very Important)

In multi-dimensional arrays, operations can be applied along specific axes.

---

### Example Array

```python
a = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

---

### Axis Meaning

- `axis = 0` → operate **column-wise**
- `axis = 1` → operate **row-wise**

---

### Visualization

Matrix:

```
[1  2  3]
[4  5  6]
```

---

### Column-wise Sum (`axis=0`)

```python
np.sum(a, axis=0)
```

Output:

```
[5 7 9]
```

Explanation:

- (1+4), (2+5), (3+6)

---

### Row-wise Sum (`axis=1`)

```python
np.sum(a, axis=1)
```

Output:

```
[ 6 15]
```

Explanation:

- (1+2+3), (4+5+6)

---

### Other Aggregations with Axis

```python
np.mean(a, axis=0)
np.std(a, axis=1)
np.max(a, axis=1)
np.min(a, axis=0)
```

---

## 3.6 Key Concept: Broadcasting (Short Intro)

Even if shapes differ:

```python
a = np.array([1, 2, 3])
b = 2

print(a * b)  # [2 4 6]
```

➡ Scalar is broadcast to match array

# 4. Linear Algebra in NumPy

## 4.1 Dot Product & Matrix Multiplication

### (A) Dot Product (1D vectors)

\mathbf{a}\cdot\mathbf{b}=\sum\_{i=1}^{n} a_i b_i

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(np.dot(a, b))  # 32
```

---

### (B) Matrix Multiplication

C*{ij}=\sum*{k} A*{ik} B*{kj}

```python
A = np.array([[1, 2],
              [3, 4]])

B = np.array([[5, 6],
              [7, 8]])

print(A @ B)
# OR
print(np.matmul(A, B))
```

Output:

```
[[19 22]
 [43 50]]
```

---

### Key Difference

| Operation     | Meaning               |
| ------------- | --------------------- |
| `*`           | Element-wise          |
| `@` / `dot()` | Matrix multiplication |

---

## 4.2 Transpose

Flips rows ↔ columns

(A^T)_{ij}=A_{ji}

```python
A = np.array([[1, 2, 3],
              [4, 5, 6]])

print(A.T)
```

Output:

```
[[1 4]
 [2 5]
 [3 6]]
```

---

## 4.3 Identity Matrix

Square matrix with 1s on diagonal

I_n = \begin{bmatrix}1 & 0 & \cdots & 0 \ 0 & 1 & \cdots & 0 \ \vdots & \vdots & \ddots & \vdots \ 0 & 0 & \cdots & 1\end{bmatrix}

```python
I = np.eye(3)
print(I)
```

Output:

```
[[1. 0. 0.]
 [0. 1. 0.]
 [0. 0. 1.]]
```

---

## 4.4 Inverse of Matrix

Matrix inverse satisfies:

[
A \cdot A^{-1} = I
]

```python
A = np.array([[1, 2],
              [3, 4]])

A_inv = np.linalg.inv(A)

print(A_inv)
```

---

### Verification

```python
print(A @ A_inv)  # ≈ Identity matrix
```

---

### Important Notes

- Only defined for **square, non-singular matrices**
- Determinant ≠ 0

---

## 4.5 Eigenvalues & Eigenvectors

Fundamental for:

- PCA (dimensionality reduction)
- Stability analysis
- Feature extraction

---

### Definition

A\mathbf{v} = \lambda \mathbf{v}

Where:

- ( \lambda ) → eigenvalue
- ( \mathbf{v} ) → eigenvector

---

### Computation

```python
A = np.array([[2, 0],
              [0, 3]])

values, vectors = np.linalg.eig(A)

print("Eigenvalues:", values)
print("Eigenvectors:\n", vectors)
```

---

### Interpretation

- Eigenvalues → scaling factors
- Eigenvectors → directions

---

## 4.6 Solving Linear Equations

System:

A\mathbf{x} = \mathbf{b}

---

### Using `np.linalg.solve()`

```python
A = np.array([[2, 1],
              [1, 3]])

b = np.array([8, 13])

x = np.linalg.solve(A, b)

print(x)
```

---

### Why not use inverse?

Avoid:

```python
x = np.linalg.inv(A) @ b
```

Preferred:

```python
np.linalg.solve(A, b)
```
