### (1) 1D Indexing

```python
import numpy as np

a = np.array([10, 20, 30, 40])

print(a[0])   # 10
print(a[-1])  # 40 (last element)
```

**Key Points:**

- Zero-based indexing
- Negative indices access from end

---

### (2) 2D Indexing

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])

print(a[0, 1])  # 2
print(a[1, 2])  # 6
```

**Interpretation:**

- `a[row, column]`

---

### (3) Multi-Dimensional Indexing

```python
a = np.array([[[1, 2], [3, 4]],
              [[5, 6], [7, 8]]])

print(a[1, 0, 1])  # 6
```

**Interpretation:**

- `a[depth, row, column]`

---

## 2 Slicing

Slicing extracts subarrays using the format:

[
\text{start : stop : step}
]

---

### (1) 1D Slicing

```python
a = np.array([10, 20, 30, 40, 50])

print(a[1:4])    # [20 30 40]
print(a[:3])     # [10 20 30]
print(a[::2])    # [10 30 50]
```

---

### (2) 2D Slicing

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])

print(a[:, 1])     # Column 1 → [2 5]
print(a[0, :])     # Row 0 → [1 2 3]
print(a[0:2, 1:3]) # Submatrix
```

Output:

```
[[2 3]
 [5 6]]
```

---

### Important Concept: View vs Copy

- Slicing returns a **view (not a copy)**
- Modifying slice affects original array

```python
a = np.array([1,2,3,4])
b = a[1:3]

b[0] = 99
print(a)  # [1 99 3 4]
```

## 2.4 Boolean Indexing

Used for **filtering data based on conditions**.

```python
a = np.array([10, 20, 30, 40])

print(a[a > 20])   # [30 40]
```

---

### Multiple Conditions

```python
print(a[(a > 10) & (a < 40)])  # [20 30]
```

---

## 2.5 Fancy Indexing

Selecting elements using **index arrays**

---

### (1) 1D Fancy Indexing

```python
a = np.array([10, 20, 30, 40])

indices = [0, 2]
print(a[indices])   # [10 30]
```

---

### (2) 2D Fancy Indexing

```python
a = np.array([[1, 2],
              [3, 4]])

rows = [0, 1]
cols = [1, 0]

print(a[rows, cols])  # [2 3]
```

---

### Key Difference:

| Type           | Behavior |
| -------------- | -------- |
| Slicing        | View     |
| Fancy Indexing | Copy     |

---

## 2.6 Iterating Arrays

Iteration is less preferred in NumPy (vectorization is faster), but still useful.

---

### (1) 1D Iteration

```python
a = np.array([1, 2, 3])

for x in a:
    print(x)
```

---

### (2) 2D Iteration (Row-wise)

```python
a = np.array([[1, 2],
              [3, 4]])

for row in a:
    print(row)
```

---

### (3) Element-wise Iteration

```python
for x in np.nditer(a):
    print(x)
```

---

### (4) Iteration with Index

```python
for idx, val in np.ndenumerate(a):
    print(idx, val)
```
